# 💫 Descripcion:
Este proyecto es un e-commerce enfocado en ofrecer una experiencia de outlet virtual. A través de nuestra plataforma, los usuarios pueden explorar y adquirir prendas de las mejores marcas del mercado a precios reducidos. Nuestro objetivo es brindar una experiencia de compra sencilla y accesible, permitiendo a los clientes acceder a productos de alta calidad desde la comodidad de su hogar. ¡Descubre una gran variedad de estilos y marcas exclusivas con grandes descuentos!

# 🏗️ Instalación:

1. Clonar el repositorio en la carpeta en la cual se trabajara:
```shell
git clone https://github.com/beltracr/worldOutlet-TF300H.git
```
2. Instalacion de dependencias
```shell
npm install
```

# 🛫 Inicializacion:
```shell
ng serve -o
```
